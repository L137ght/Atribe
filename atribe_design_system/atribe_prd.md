# Atribe Product Requirements

## Product Purpose
Atribe allows users to support creators when shopping online by routing any product link through a creator’s affiliate link.

## Key Capabilities
- Works across multiple brands (not just Amazon)
- Creators can add their own affiliate links per brand/domain

## Core Themes
- Community (tribe)
- Support creators through affiliate links
- Control over economic impact
- Cross-platform compatibility

## Design Goals
- Clean, minimal, modern (inspired by Stripe, Linear, Notion)
- Trustworthy and slightly premium
- Low cognitive load
- Strong focus on input → output clarity

## Screens to Design
1. **Login Screen:** "Continue with Google"
2. **Intent Selection:** "Support creators" vs "I am a creator"
3. **Creator Onboarding:** Name + platform
4. **Add Affiliate Links:** Input link, auto-detect domain, list domains
5. **Creator Dashboard:** List supported brands, edit/remove
6. **Creator Discovery:** Search, filter by brand/domain support
7. **Creator Selection:** Multi-select, assign weights
8. **Home Screen (Main):** URL input, detected domain, selected creators, attribution preview, open/copy link actions
9. **Fallback State:** When no creator supports the domain
10. **Feedback UI:** Confirmation "You supported [Creator]"
